# Doc types in formbook

A doc type exists for a court only if `<court>/<doctype>/typst/main.typ` exists. Folders `courts/**/typst/` without `main.typ` are empty scaffolds (374 of 837 at the time of writing). Counts below are the number of templates (court folders) per doc-type folder name, as of this skill's commit.

| Doc type folder | Templates | What it is |
|---|---|---|
| `motion-brief` | 177 | Memorandum of law / brief in support of or opposing a motion (district courts, state trial courts) |
| `complaint` | 99 | Civil complaint (pleading paper where the court requires it) |
| `adversary-complaint` | 91 | Bankruptcy adversary-proceeding complaint |
| `opening-brief` | 29 | Appellant's opening brief |
| `answering-brief` | 28 | Appellee's answering brief |
| `reply-brief` | 21 | Reply brief |
| `petition-for-review`, `petition` | 2 + 2 | Petitions (e.g. Tax Court, agency review) |
| `amicus-brief` | 2 | Amicus curiae brief |
| `trial-brief`, `pretrial-memorandum`, `petition-supplement`, `petition-for-discretionary-review`, `patent-owner-response`, `opening-brief-on-the-merits`, `notice-of-opposition`, `merits-brief`, `cert-petition`, `brief-on-the-merits`, `brief-on-appeal` | 1 each | Court-specific names (supreme courts, PTAB/TTAB, state appellate courts) |
| `.` (court root) | 1 | Ninth Circuit reference template (older layout: `courts/ninth-circuit/court-of-appeals/typst/`, with `answering-brief/` and `reply-brief/` subfolders) |

Also in the repo: `rules.md` and `checks.yaml` (mechanical court-rule checks) exist only for the reference court (`ca9`) today.

## Regenerate

From the repo root:

```sh
# templates per doc type (folder name)
find courts -type d -name typst | while read -r t; do
  [ -f "$t/main.typ" ] && basename "$(dirname "$t")"
done | sort | uniq -c | sort -rn

# every template, as path
find courts -path '*/typst/main.typ' | sed 's|/typst/main.typ$||' | sort

# doc types for one court
sh skills/formbook/scripts/find.sh <alias>

# courts that have a given doc type
find courts -path "*/$DOCTYPE/typst/main.typ" | sed "s|/$DOCTYPE/typst/main.typ$||"
```

For a status view per court, `STATUS.md` (generated by `tools/tracker.sh`) and `court.json` (`status`: `todo` and so on; only the repo owner sets `done`).

## Choosing

- Same court, wrong doc type: not interchangeable even between `opening-brief` and `answering-brief` (different required sections and word limits).
- Court has no folder for your doc type: look for it at a sibling court only as a model to copy for WRITE, never as a stand-in for filing.
- A template existing means it passed the loop's tier-1/tier-2 review for its sample; it is not a guarantee for every filing. Read its README "Known gaps" before relying on it.
