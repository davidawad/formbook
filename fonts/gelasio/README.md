# Gelasio

- Substitutes for: Georgia (the face named by court rules; proprietary, not bundled).
- Metric compatibility: advance widths match Georgia (metric-compatible replacement, by Eben Sorkin).
- Styles: Regular, Bold, Italic, BoldItalic (4 TTFs).
- Licence: SIL Open Font License 1.1 (`OFL.txt`). Redistribution with this repository (GPL v3) is permitted; the fonts are bundled unmodified as separate data files and are not sold on their own.
- Source: see `SOURCE.md` (upstream URL, pinned commit, SHA-256).
- Typst: `#set text(font: "Gelasio")`; proof in `fonts/tests/gelasio.typ`.
