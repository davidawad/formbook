# fb-595.54.82: the serial lane's changes to the shared document model

The serial lane changes the shared model (lib/typst/xdoc.typ, lib/pandoc/xdoc.lua, lib/latex/xdoc.lua,
lib/docx/xdoc.lua, tools/fb enginegen) for the requests of the batch lanes (docs/open-items/fb-595.54.*.md), in
order of how many doc folders asked. Each feature is one commit ending "(fb-595.54.82)", with a model test
(tools/fb/src/enginegen/model_tests.rs) and its layout.yaml grammar in docs/EVAL-LOOP.md, "Generated engines".
Folder counts are those of the lanes' notes (distinct doc folders that asked, worked-around ones included).

fb-595.54.13 (Pennsylvania) changed the model in parallel; the merge kept one implementation each (heading numbers,
URL breaks, the frontmatter marker escapes, word counts: `{body_words}` and `{xd.words}` both) and its own features:
field defaults, the footnote clearance (9.1 pt), unsplit notes, no widow or orphan control for a paragraph that
anchors a note (in every engine, which settles the 25 folders' widow/orphan request), CommonMark lists.

## Not implemented (requests open, folders)

- A page list too wide for its column on a line of its own, page ranges (10): Word cannot wrap the text after a
  right tab alike; each engine needs the same list breaking.
- The line-fit tolerance at a line typst fills to within hundredths of a point (10): LibreOffice's twip rounding,
  newtx's per-glyph drift (a bias that scales with the line).
- Word's footnote area (8): a body line fewer above notes at 11 or 14 pt, the note gap with one note, the mark width.
- typst setting a note on another page than its mark (7).
- A cover whose type size is chosen to fit one page (7).
- Contents and authorities under one title, the points' authorities under each heading (13).
- Tables in the body (5), pleading paper (4), paragraph rules (a short line flush left, ":" kept with the next; 4),
  two documents in one filing (2), a page number at the top and a running header (2), other authority schemas
  (`{group, items}`: 6, a decision).
- Decisions for David, as the lanes recorded them: the Minnesota cover's top margin (4), the Louisiana motion and
  amicus paper, the other items in the lanes' notes.

## For the lanes

- Hawaii Supreme Court petition-for-discretionary-review (typst only): its `caption_right` holds empty items, which
  are now lines of their pitch (the empty-line feature Hawaii asked for); its cover runs to two pages
  (DEF-COVER-001). The layout should drop the empty items or make them optional.
- `fb engines gen --check` reports a folder generated before this lane's changes STALE: docx/reference.xml gains the
  quotation list styles (Xd Quote List 1..3), latex/template.tex master's 9.1 pt footnote clearance. Regenerate
  (`fb engines gen <folder>`) before rendering again; nothing else in the generated files moves for a layout that
  uses none of the new keys.
- Folders already on the model render differently with the model at HEAD (the URL rule, the heading weight, the
  marks, the sign tokens and the other fixes above) than their committed outputs: `check.sh --no-render` passes on
  the committed ones; a lane that renders again gets the model's current output. The sweep (every layout.yaml folder,
  three engines, against master's own re-render) found no result worse than master's but the Hawaii cover and a
  Vermont docx line LibreOffice misses by its twip rounding (report mode).

## Serial lane 2: the batch results reconciled onto master (fb-595.54.82)

Three batch branches changed the shared model in parallel with lane 1 and could not land. Each was ported onto
master's model (its own implementation kept where both had one), its court folders brought over and checked, one
commit each, then every folder on the model re-rendered.

### Dropped, and why

- typst's TIE (a text block 0.02 pt wider) and the global newtx bias 0.075 (16-a2): master keeps 0.05, measured over
  every folder on the model; the one Wisconsin line that needs more has its folder's `latex_bias`.
- The branches' own heading labels, word counter, `{field?}`, URL rules (16-a2's after a run of `/?&`, 15-a1's and
  14-a2's typst-native breaks), note widow scopes, `bind_closing`/`ties`, `commonmark_lists`, list-index lookup,
  reader without fancy lists, emphasis toggles, heading needles: master has its own (`number`, count-words,
  `{field|}`, url-pieces, note runs, bind_punct, ...); the Wisconsin layouts were moved to master's grammar
  (`number`, `{xd.words}`, `{certification_order|}`, passim n+1).
- 16-a2's TS1 minus: master sets the minus from newtxmath at the typst face's advance (TS1 glyphs are bitmaps).
- 15-a1's notes split as typst splits them, and 14-a2's empty value gives no paragraph: master decided otherwise
  (notes never split; an empty value is a blank line). The Ohio PDR, answering and reply layouts drop
  `widows: true` (with notes never split it set one line alone above a note in typst).
- 15-a1's needle words after a mark run on past italics: the needle's words before a find (16-a2) cover the case
  without crossing a note's mark.
- 14-a2's re-renders of other courts and its Kansas Court of Appeals files: master's are newer (fb-595.54.62).

### The re-render (every folder with a typst/layout.yaml, 319, three engines)

286 folders' engines were stale (generated before fb-595.54.13's 9.1 pt clearance and quotation-list styles): all
regenerated, rendered and checked. Every engine stamped green before is stamped green after (none lost, none added).
Engines the sweep would have added to folders that ship without them (28 folders, some on purpose, fb-595.54.77)
were not kept.
