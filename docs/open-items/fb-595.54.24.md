# fb-595.54.24: open items (Supreme Court of New Hampshire)

Folders of the bead: `courts/first-circuit/new-hampshire/state/supreme-court` and its nine doc folders. All nine
doc folders had the same typst template (one family). Four are now on the shared document model. The court root has
no template (`typst/.gitkeep` only), so there is nothing to port there. The other five need a feature the model lacks
and are left as they were.

| folder | state |
|---|---|
| court root | no template; nothing to port |
| `motion-brief` | on the model: typst, latex, docx; XENG-001..003 pass on latex and docx (134/134 lines, 6 = 6 pages); `cross_engine: gate` |
| `petition-for-rehearing` | on the model: typst, latex, docx; tier 1 0 failed on all three; XENG fails on latex and docx (model defect 1 below); `cross_engine: report` |
| `petition-for-writ` | on the model: typst, latex, docx; tier 1 0 failed on all three; docx XENG passes (497/497); latex fails (model defect 2); `cross_engine: report` |
| `petition-for-review` | on the model: typst, latex, docx; tier 1 0 failed on all three; docx XENG passes (575/575); latex fails (model defect 3); `cross_engine: report` |
| `amicus-brief`, `answering-brief`, `brief-on-the-merits`, `petition-for-discretionary-review`, `reply-brief` | typst only, template unchanged; `eval.yaml` sets `cross_engine: report` (shared-model request 1) |

The four ported folders share one layout (`typst/layout.yaml`), built from SCR 16(1), 16(2), 16(10), 16(11), 21(1)
and 22: 13 pt Times New Roman; Word's 1.5-line pitch (22.45 pt, the nearest whole twip to 1.5 x 1.15 x 13 pt);
1.5 in margins; pages numbered from the cover as page 1 with the cover's number suppressed; footnotes in 13 pt
single spaced (as every filed exemplar sets them); the cover; the signature block and each certificate never split.
`petition-for-review` adds a table of contents. The other three set the cover as `front` blocks closed by a page
break, because docx writes a `cover` only before tables (the NY defect in docs/open-items/fb-595.54.34.md).

The writ INPUT's questions presented open with "I.", "II.", and so on. Those periods are now escaped (`II\.`):
cmarker reads these lines as paragraphs, but pandoc's `fancy_lists` reads "II." onward as a roman-numbered list,
which broke XENG-003 from p3 line 12 in latex and docx. Both readers now see paragraphs; the printed text is
unchanged.

## Shared-model requests (for fb-595.54.82)

1. **Authorities as a keyed list cited by link.** Feature: a table of authorities from
   `authorities: [{key, category, text}]`, grouped by `category` (cases, statutes, rules, other) under the court
   headings Cases, Statutes, Rules, Other Authorities. Each entry's pages come from body links `[cite](toa:<key>)`:
   the link prints its text, and "passim" is printed past five pages. The model reads only
   `authorities: [{heading, entries: [{cite, find}]}]`. `authority-entries` (lib/typst/xdoc.typ) reads `g.entries` on
   each item, so these INPUTs fail the typst render even without an `authorities` key in layout.yaml. Neither
   engine strips a `toa:` link either (typst would write a URI annotation). Folders: amicus-brief (79 entries,
   124 links), answering-brief (29, 195), brief-on-the-merits (61, 126), petition-for-discretionary-review (18, 23),
   reply-brief (16, 21). Rewriting the INPUTs into the model's shape would change the court's markdown contract,
   which is a decision, not a port. petition-for-review has 24 `toa:` links and no list; it renders, and the links
   print their text.
2. **Certificates placed by type.** The old template set every certificate except `type: service` *before* the
   signature (NH-SEC-003: the decisions-below certification comes "immediately before the signature line"; the
   certificate of compliance) and the service certificate after it. The model's `each` cannot filter a list by a
   field's value. Folders: amicus-brief, answering-brief (compliance and service). The four ported folders have only
   a service certificate.
3. **An empty value.** `proceeding: ""` (motion-brief, petition-for-rehearing) is an
   empty paragraph: typst sets it with no height, Word with one line. On the docx cover every line below it sits
   14.94 pt lower (diagnostic only; XENG passes).

## Model defects found (folders left at `cross_engine: report`)

1. **Widow control around a footnote.** A paragraph whose last line anchors a footnote has no widow or club penalty in
   LaTeX and Word (lib/latex/xdoc.lua `para`, lib/docx/xdoc.lua). typst keeps its default widow cost, so it moves
   two lines where the others move one. petition-for-rehearing, p6 line 24: the paragraph "Verizon's current
   federal (interstate) access tariff ... of Record).[^2] Section 3.5 states:" is 2 + 2 lines in typst and 3 + 1 in
   latex and docx. From there latex fails XENG-002/003 (pages 8 to 11 start on other words, 228/253 lines) and docx
   fails XENG-001 too (10 pages, typst 11). The typst model needs `footnote-widows` as LaTeX and Word set it, or
   the same "no widow control" for such a paragraph.
2. **No break after a slash inside a word in LaTeX.** typst breaks after "/" inside a word ("and/or"), and Word gets
   the same break from the zero-width space lib/docx/xdoc.lua inserts. lib/latex has no such break. petition-for-writ
   latex, p5 line 1: typst ends the line at "Constitution and/" and latex at "Constitution", so 478/497 lines and
   15 of 20 page ends differ.
3. **A line typst fills to 0.0015 pt.** petition-for-review latex, p18 line 9: typst ends "... and that the detail"
   at 503.9985 of 504 pt, and latex sets "detail" on the next line (573/575 lines; pages equal). The LaTeX text
   block's tolerance for Times New Roman (the 0.05 bp of the pilot) does not cover this line.
