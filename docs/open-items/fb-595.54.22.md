## Shared-model requests

1. **TeX Gyre Schola (Century Schoolbook) in LaTeX.** This is already listed under "Not yet in the model" in
   docs/EVAL-LOOP.md, and batches fb-595.54.36, .48, .52, .54, .63 and .77 ask for it too. All nine templates set
   `TeX Gyre Schola`, the vendored Century Schoolbook (rules.md NC-FORM-003: the style manual names Constantia and
   the Century family as examples, and the template declares Century Schoolbook). `tools/fb/src/enginegen/gen.rs`
   `latex_face` refuses the face ("the shared document model does not set Schola in LaTeX yet"), so `fb engines gen`
   can write no latex engine for any folder here. Rule 26(g)(1) (NC-FORM-002) leaves the face open, so Times New
   Roman would satisfy tier 1. But the exemplars of other filers set Century Schoolbook: `answering-brief`,
   `brief-on-the-merits`, `motion-brief`, `petition-for-rehearing` and `reply-brief` do, and `amicus-brief` sets
   Century (`pdffonts`). The others set Constantia (`petition-for-discretionary-review`, and the headings of
   `petition-for-review`) and Equity (`petition-for-writ`). Changing the face is a tier-2 decision this bead does not
   make. Folders: all nine.
2. **A column cell ruled on its right and bottom.** NC-CONV-001: on the cover, the caption (parties, "v.", roles)
   sits in a left cell that has a 0.75 pt rule on its right and bottom edges. The lower-court references are centred
   beside it. (The typst templates draw the box instead of the ")" column
   that rules.md names; both are listed under "Not yet in the model" in docs/EVAL-LOOP.md: the ")" column beside a
   caption, the ruled box.) The model's `columns` cells have no stroke, and a `{rule}` block spans its container
   only horizontally, so neither the vertical rule nor the box can be built. Needed: e.g. a column's
   `border: {right, bottom}` (typst: the cell's stroke; LaTeX: `\vrule` and a bottom `\hrule` in the cell's box;
   Word: the table cell's borders). Folders: all nine. Evidence: page 1 of every `usage/OUTPUT-*.typst.pdf`.
3. **A level-1 heading that starts a page (except the first of the body).** In `answering-brief`,
   `brief-on-the-merits`, `motion-brief`, `petition-for-review` and `reply-brief`, each main section (Issues
   Presented, Statement of the Case, Argument, Conclusion, Certificate of Service) starts a new page, as in the filed
   exemplars. The template does a weak `pagebreak` before every level-1 heading after the body's first. The model's
   heading styles have `above`/`below` only; `{break: true}` is a block, and `tail.break` breaks once before the
   tail. Needed: a heading style `break: true` (typst: a weak `pagebreak`; LaTeX: `\clearpage`; Word: page break
   before). Folders: the five named.
4. **A table of authorities grouped by kind, with "passim".** Each INPUT's frontmatter holds `authorities` as a map
   `{key: {kind, name, cite, find}}`. The template groups the rows under a fixed heading per `kind` (Cases,
   Statutes, Rules, Constitutional Provisions, Other Authorities; the titles and their order are the folder's) and
   prints "passim" for an authority cited on 7 or more pages. The model reads `authorities: [{heading, entries:
   [{cite, find}]}]` and has no "passim". Moving would need either a rewrite of all nine INPUTs' frontmatter (a new
   shape) or a model that reads a `kind` grouping (`authorities: {group_by: kind, groups: [{kind, title}]}`), plus
   `authorities.passim: <n>`. Folders: all nine (10 to 133 authorities each; the renders print "passim" in
   `amicus-brief`, `answering-brief`, `brief-on-the-merits`, `petition-for-rehearing`, `petition-for-writ` and
   `reply-brief`).

The model also does not yet have two smaller things these templates use. Neither blocks a move on its own:

- A gap between body paragraphs: the templates set 0.6 em (7.2 pt) beyond the double-spaced pitch
  (`body-gap`, a style choice), and the model's body paragraphs touch at the body pitch (also fb-595.54.36, item 4).
- The page number in a footer `footer-descent: 0.4in` below the text (a style choice). The model's footer sits at
  30 % of the bottom margin.
