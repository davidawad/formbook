## Shared-model requests (for fb-595.54.82)

- **S1. EB Garamond's lining figures in LaTeX.** The generated `latex/template.tex` loads `\usepackage{ebgaramond}`
  (tools/fb/src/enginegen/gen.rs, `latex_face`). That package defaults to old-style figures, which are narrower. typst and
  Word set EB Garamond's default lining figures. As a result, every LaTeX line that holds digits fits more.
  - Needed: `\usepackage[lining]{ebgaramond}`, then re-measure the face's bias.
  - Folders: `6d/motion-brief`, and every EB Garamond folder once it is ported (`6d` amicus, answering, opening,
    petition-for-writ, reply).
  - Evidence: `fb diff --engines` of `6d/motion-brief`, latex: 69/79 lines identical, first differing at p2 line 21.
    typst ends that line after "Cal.App.4th"; LaTeX fits "1344," as well. The width diagnostic shows p2 line 16 21.52 pt
    narrower ("... (1997) 57 Cal.App.4th 1189, 1198-1199.)"). From there p3 and p4 start a line early. The cover line
    "v. / Court of Appeal Case No. H049566" shows the old-style digits too.
- **S2. A cover without tables in Word.** lib/docx/xdoc.lua sets `spec.cover` only inside `if paged`, that is, when
  the layout has `contents` or `authorities`. A layout with a `cover` and no tables gets no cover in the docx. Before the
  workaround below, the `6d/motion-brief` docx started at "TO:" and had 3 pages against typst's 4. LaTeX and typst set
  the cover. `6d/motion-brief` therefore sets its cover as `front` blocks ending in `{break: true}`, which all three
  engines lay out alike. Once the cover is emitted outside `paged`, it can move back to `cover:`.
- **S3. The California `authorities:` map.** lib/typst/xdoc.typ `authority-entries` iterates `meta.authorities` as a
  list of groups. The California INPUTs give a map (`{key: {kind, name, cite}}`; 65:R3), so the typst render stops
  with "cannot access fields on type array" even when the layout has no `authorities` table. `6d/motion-brief` removes
  the field in its template before calling `xdoc` (its motion sets no table; the Lua side reads it with `ipairs` and
  finds nothing). The model could ignore a non-list `authorities`, or read the map (65:R3).

## Tier 2, `6d/motion-brief` (4 pages, all looked at in typst, latex and docx)

- Numbered headings (65:R2): the old template numbered levels 2 to 5 (I. / A. / 1. / a.). The model does not, so a
  motion with sub-points now gets bold unnumbered headings. The sample has only one level-1 heading, so its render is
  unaffected.
- Cover (65:R5): the old cover chose the largest gap at which it fit one page. The layout now uses fixed gaps (15.6,
  25 pt). These fit this sample with half a page to spare, but a long caption or counsel list could overflow.
- Closing (65:R7): the old template kept the last paragraph with the signature. The model keeps only the closing
  itself whole. In this sample p4 holds the end of the second-to-last paragraph, the last one and the closing.
- Pitches: single 16.95 pt (EB Garamond's ascender + descender at 13 pt, as the old template set it) and 1.5 lines
  25.45 pt, about the old render's pitch (0.65 em leading on 16.97 pt lines); 4 pages, as before.
