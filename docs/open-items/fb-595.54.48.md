## Shared-model requests (for fb-595.54.82)

- **S1. EB Garamond's lining figures in LaTeX.** The generated `latex/template.tex` loads `\usepackage{ebgaramond}`
  (tools/fb/src/enginegen/gen.rs, `latex_face`). That package defaults to old-style figures, which are narrower. typst and
  Word set EB Garamond's default lining figures. As a result, every LaTeX line that holds digits fits more.
  - Needed: `\usepackage[lining]{ebgaramond}`, then re-measure the face's bias.
  - Folders: `6d/motion-brief`, and every EB Garamond folder once it is ported (`6d` amicus, answering, opening,
    petition-for-writ, reply).
  - Evidence: `fb diff --engines` of `6d/motion-brief`, latex: 69/79 lines identical, first differing at p2 line 21.
    typst ends that line after "Cal.App.4th"; LaTeX fits "1344," as well. The width diagnostic shows p2 line 16 21.52 pt
    narrower ("... (1997) 57 Cal.App.4th 1189, 1198-1199.)"). From there p3 and p4 start a line early. The cover line
    "v. / Court of Appeal Case No. H049566" shows the old-style digits too.
- **S2. A cover without tables in Word.** lib/docx/xdoc.lua sets `spec.cover` only inside `if paged`, that is, when
  the layout has `contents` or `authorities`. A layout with a `cover` and no tables gets no cover in the docx. Before the
  workaround below, the `6d/motion-brief` docx started at "TO:" and had 3 pages against typst's 4. LaTeX and typst set
  the cover. `6d/motion-brief` therefore sets its cover as `front` blocks ending in `{break: true}`, which all three
  engines lay out alike. Once the cover is emitted outside `paged`, it can move back to `cover:`.
- **S3. The California `authorities:` map.** lib/typst/xdoc.typ `authority-entries` iterates `meta.authorities` as a
  list of groups. The California INPUTs give a map (`{key: {kind, name, cite}}`; 65:R3), so the typst render stops
  with "cannot access fields on type array" even when the layout has no `authorities` table. `6d/motion-brief` removes
  the field in its template before calling `xdoc` (its motion sets no table; the Lua side reads it with `ipairs` and
  finds nothing). The model could ignore a non-list `authorities`, or read the map (65:R3).

## Tier 2, `6d/motion-brief` (4 pages, all looked at in typst, latex and docx)

- Numbered headings (65:R2): the old template numbered levels 2 to 5 (I. / A. / 1. / a.). The model does not, so a
  motion with sub-points now gets bold unnumbered headings. The sample has only one level-1 heading, so its render is
  unaffected.
- Cover (65:R5): the old cover chose the largest gap at which it fit one page. The layout now uses fixed gaps (15.6,
  25 pt). These fit this sample with half a page to spare, but a long caption or counsel list could overflow.
- Closing (65:R7): the old template kept the last paragraph with the signature. The model keeps only the closing
  itself whole. In this sample p4 holds the end of the second-to-last paragraph, the last one and the closing.
- Pitches: single 16.95 pt (EB Garamond's ascender + descender at 13 pt, as the old template set it) and 1.5 lines
  25.45 pt, about the old render's pitch (0.65 em leading on 16.97 pt lines); 4 pages, as before.

### Shared-model requests, second serial lane

- **S4. `\xd@glyph` without `\leavevmode` (LaTeX, EB Garamond).** lib/latex/xdoc.sty `\xd@glyph` starts with
  `\begingroup\pdfliteral...\hbox`; at the start of a paragraph TeX is still in vertical mode, so the box of EB Garamond's
  regular T (the generated `latex_specials`) is set as a line of its own above the paragraph and the indent is lost.
  Every paragraph that opens with "T" breaks. Evidence: `6d/motion-brief` latex p2 "TO:" and "This motion": the T at
  x 108, y 72, "O:" at x 144 a line lower; 76/78 lines. With `\leavevmode` before `\begingroup` (tried locally, not
  committed) the latex render passes 78/78. Folders: every EB Garamond folder (6d motion, amicus, answering, opening,
  petition-for-writ, reply; also 5d's motion once regenerated).
- **S5. The checker's LaTeX calibration misses the generated EB Garamond package.** tools/fb/src/check/calibtex.rs
  probes the template for `\usepackage{ebgaramond}`; the generator now writes `\usepackage[lining,tabular]{ebgaramond}`,
  so the check calibrates on typst's EB Garamond (14 pt = 18.27 pt word height) while the PDF holds the Type 1 face
  (12.86 pt words at 13 pt): DEF-FORM-003 fails on every EB Garamond latex render. With a probe line that matches (tried
  locally) the calibration is 13.71 pt and DEF-FORM-003 passes. Folders: as S4.
- **S6. Word sets Schola's ligatures.** The generated `docx/reference.xml` has no `<w14:ligatures w14:val="none"/>` in
  `w:docDefaults`, so tools/fb/src/doclig.rs does not convert with the `:-liga` font names and LibreOffice forms fi, ff,
  ffi (0.5 to 1 pt narrower: "Certificate" 63.25 against typst's 63.79). Lines typst fills to the measure take a word
  more. Evidence: `1d/reply-brief` docx p14, p20, p28; converting the same .docx with `:-liga` names (tried locally)
  gives 1113/1114 lines. Folders: every Schola (and EB Garamond, Gelasio) folder with a generated docx.
- **S7. A keyed authority whose citation runs over a page end (Word).** lib/docx/xdoc.lua gives a `toa:` link's needle
  the whole citation as its find, so docxpages.rs reads the page where the citation ends; typst and LaTeX mark the
  first word's page. Evidence: `1d/reply-brief` TOA "Kraus v. Trinity Management Services, Inc. (2000) 23 Cal.4th 116":
  typst 21, docx 22 (the citation starts on the last line of p21).
- **S8. No break after a slash inside a word in LaTeX.** typst (Unicode line breaking) and lib/docx/xdoc.lua (`breaks`,
  a zero-width space) break after "/" inside a word before a letter; lib/latex has no such `\allowbreak`. Evidence:
  `1d/opening-brief` latex p36 "Gallo/Madsen", `1d/petition-for-discretionary-review` latex p12 "criminal/regulatory".
  (Also the cover's "Plaintiffs/Respondents" of `1d/answering-brief`.)
- **S9. typst sorts keyed authorities with their punctuation.** lib/typst/xdoc.typ `sort-key` puts
  `.replace(regex("[^a-z0-9 ]"), "")` on the line after the `#let`, where typst does not read it as a method call, so the
  key keeps its periods; lib/pandoc/xdoc.lua strips them. Evidence: `1d/opening-brief` p6, typst "People v. E.W.A.P.
  Inc." before "People v. Englebrecht", LaTeX and Word after (a debug render of `keyed-entries` prints
  "people v. e.w.a.p. inc. (1980) ..."). Fix: parenthesize the expression or put the call on one line.
- **S10. An authorities row whose text leaves no room for the leader.** typst sets one leader dot glued to the page list
  (".34, 37"), LaTeX none (the list alone at the right); the diff reads ".34," as another word. Evidence:
  `1d/opening-brief` p6 "People ex rel. Reisig v. Acuna (2010) 182 Cal.App.4th 866", "People v. Englebrecht".
- **S11. A URL piece wider than the measure.** The shared URL rule breaks only after a slash, a dot or hyphen before a
  letter, "?" or "!"; `1d/answering-brief` note 1 holds
  `https://ballotpedia.org/California_Proposition_11,_Constitutional_Right_to_Privacy_Amendment_(1972)`, whose last piece
  (underscores and commas only) runs 60 pt into the right margin (DEF-FORM-002 fails at p12, right edge 600.17 > 540).
  The old template passed. Needed: a break after "_" (or ","), or a piece wider than the line broken anywhere, in every
  engine. The folder stays on its old template until then.
- **S12. A URL that ends in a slash before ")" (LaTeX, Schola).** The pieces end ".../proposal/" | ").)"; the
  `\allowbreak` and xeschola's `\xeflush` of ")" leave a gap pdftotext reads as a space ("proposal/ ).)"). Evidence:
  `1d/amicus-brief` latex p5 note 1.
- **S13. Schola's bold space in LaTeX.** xeschola.sty sets the bold space to the vendored 0.278 em in a `selectfont`
  hook, but the PDF shows 3.73 pt (TeX Live's 0.287 em) between bold words at 13 pt, against typst's 3.61, in headings
  and on the cover. A bold line typst fills to the measure breaks a word early. Evidence: `1d/petition-for-writ` p1
  notice "PUBLIC – REDACTS MATERIAL FROM SEALED RECORD" (typst 395.97 pt wide), `1d/petition-for-discretionary-review`
  p7 heading A ("... afford the parties an").
- **S14. A cover fill that does not settle in Word.** `6d/petition-for-discretionary-review` with the brief family's
  cover fills: the position needle of the cover's last block alternates 3964 / 3960 twips (669.758 / 669.558 pt) pass
  after pass, and `fb render` stops ("the pages did not settle in 5 passes"). The folder sets fixed cover gaps instead.
