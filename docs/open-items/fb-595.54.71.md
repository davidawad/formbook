# fb-595.54.71: open items (Arkansas and Missouri courts of appeals on the shared model)

Folders of the bead not gated, with the reason, for the serial lane fb-595.54.82.

## Shared-model requests

### Table of authorities after a body section (Arkansas: points on appeal before the authorities)

- Feature: place the table of authorities (layout.yaml `authorities`) after a named level-1 section of the body
  instead of before the body, e.g. `authorities: {after: "Points on Appeal", ..}`; the contents still lists every
  section, the pages still count from the cover.
- Folders: `courts/eighth-circuit/arkansas/state/court-of-appeals/opening-brief`,
  `courts/eighth-circuit/arkansas/state/court-of-appeals/answering-brief`.
- Evidence: Ark. Sup. Ct. R. 4-2(a)(2)-(4) (rules.md ARCTAPP-CONT-002, tier 1, mandatory) sets the order cover,
  table of contents, points on appeal, table of authorities, jurisdictional statement ...; both INPUTs open with
  `# Points on Appeal` and the current typst templates set the authorities after it. lib/typst/xdoc.typ sets
  `authorities-pages` before `<xd-body>` only, so porting them now would put the authorities before the points (a
  tier-1 regression). Left on their current typst template, no latex/docx (cross_engine not set: report).
- The answering brief also numbers its level-1 sections (I.-VIII. in the filed contents, "generated, not typed" per
  its INPUT): "headings numbered by the template", already listed as not in the model.

### URLs: typst breaks inside them, LaTeX and Word do not

- Feature: one rule for breaking inside a URL in all three engines (cmarker autolinks a bare URL and typst breaks a
  link after "." and "/"; lib/latex/xdoc.lua and lib/docx/xdoc.lua set it as one word).
- Folder: `courts/eighth-circuit/missouri/state/court-of-appeals/amicus-brief` (latex: 919/958 lines, docx: 797/958,
  33 vs 32 pages). First differing line: typst p7 "Practices for Supporting Transgender Students (2016), http://www2.ed."
  then "gov/about/..." in the table of authorities; LaTeX and Word carry the whole URL to the next line; the page lists
  of the table then differ and move every later page. Left on its current typst template (no layout.yaml; report).

### *passim* for a long page list in the table of authorities

- Feature: `authorities: {passim: <width>}`: a page list wider than that is set as *passim* (the current template does
  it at 4 in, Bluebook R. 3.2(a)).
- Folder: `courts/eighth-circuit/missouri/state/court-of-appeals/opening-brief` ("Hill v. Ashcroft" is cited on 18
  pages). On the model the page column widens to the list and the cite wraps one or two words a line ("Hill v.
  Ashcroft, 526 / S.W.3d 299 (Mo. / App. W.D. / 2017)"), and the length of the table then differs by engine (latex:
  1300/1371 lines, 48 vs 49 pages; docx: 1262/1371, 50 pages; first differing p2 line 2, the page numbers of the
  contents). Left on its current typst template (report).

### A list inside a quotation

- Feature: a block quotation that holds a list (lib/latex/xdoc.lua:256 and lib/docx/xdoc.lua:403 stop with "xdoc: a
  quotation holds paragraphs only").
- Folder: `courts/eighth-circuit/missouri/state/court-of-appeals/answering-brief` (the bullet points of the quoted
  ballot summary). Left on its current typst template (report).

### Missouri petition-for-writ: a caption box and a fill-in case number

- Feature: a vertical rule to the right of the caption column (like the ")" column already listed as not in the
  model), and a text block with a fallback when its field is missing ("No. {case_number}", else a blank rule of fixed
  width for the clerk).
- Folder: `courts/eighth-circuit/missouri/state/court-of-appeals/petition-for-writ` (its INPUT has no case number; the
  current template draws the box and the blank line, as the filed petition does). Not ported (report).

### The tables as PDF bookmarks (and rows of the contents)

- Arkansas Rule 4-1(e) (ARCTAPP-FORM-005) asks for a bookmark per section of Rule 4-2(a), the table of authorities
  among them; the old Arkansas and Missouri templates set the table of authorities as a heading (a contents row and a
  bookmark). lib/typst/xdoc.typ `table-title` is not a heading, so the ported folders (as the Arkansas amicus pilot)
  have no bookmark and no contents row for the tables. No check fails; a request to make the table titles bookmarks
  in all three engines.

### An optional block that is absent still sets its space above (typst only)

- lib/typst/xdoc.typ `blocks()`: at the start of a container (`first`), `lead` is set as `v(above)` before the text
  is expanded, so an `optional: true` block whose field is missing still adds its `above` in typst (LaTeX and Word
  do not): an 8.4 pt drop of the Arkansas signature block when `closing` is missing (XENG passes; baseline only).
  Worked around in the folders here with `when: closing`; the shared fix is to emit the lead only when the block
  yields a paragraph.
