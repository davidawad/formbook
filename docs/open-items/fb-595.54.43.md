## Decision needed

`MINN-COVER-001` cites Minn. R. Civ. App. P. 132.01 subd. 2, which places the court name and
docket number "one-half inch from the top center." The current templates interpret this as a
half-inch page top margin. The shared model currently exposes a single page margin and cannot
preserve that cover geometry. The court's filed examples instead place their first cover line
about one inch from the physical page top. Please decide whether the rule means one-half inch
from the physical page edge or one-half inch below the written-matter top margin. This determines
whether the shared model needs separate cover margins or whether the existing 1-inch top margin
is correct.

Until the interpretation and shared features are resolved, generating engines from an approximate
layout would risk violating a tier-1 rule. No engine renders, checker results, page reviews, or
crate tests are reported as completed for this bead.
