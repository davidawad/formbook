# fb-595.54.19: Montana Supreme Court (mont) on the shared document model

Folders: `courts/ninth-circuit/montana/state/supreme-court` and its nine doc types. The court root has no template
(`typst/` and `latex/` hold only `.gitkeep`), so it has nothing to port. Each doc type has its own `typst/layout.yaml`
written from MRAP 11 and 12 (`../rules.md`) and its old template; latex and docx are generated (`fb engines gen`).

## Tier 2, open

- The closing (date and signature) is kept whole but not with the last paragraph: it can take a page alone
  (answering-brief p85), as it did before the move (old p81).
- The certificate of compliance is no longer a row of the table of contents: the model sets it as closing blocks, not
  a heading (MRAP 12(1)(a) asks for the contents of the brief; the certificates are outside the word count).
- Cover: the old template filled the cover with `v(1fr)` above and below the title; the model has no filling space, so
  the title and counsel stand at fixed distances (36 pt) and the cover ends short.
