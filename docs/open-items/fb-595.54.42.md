## Shared-model requests

1. **Arial (Liberation Sans) in LaTeX** (the same request as fb-595.54.51 request 6, for the Florida 6th DCA).
   Fla. R. App. P. 9.045(b) allows only Arial 14-point or Bookman Old Style 14-point (FLADISTCTAPP-FORM-003, tier 1);
   all eight templates declare `#let font-family = ("Liberation Sans",)`, Arial's vendored metric twin. A Times face
   would break tier 1, and Bookman (TeX Gyre Bonum, vendored in `fonts/tex-gyre-bonum`) has no LaTeX face either.
   Evidence: with a scratch `layout.yaml` and the three-line template in `motion-brief/typst`, `fb engines gen` stops
   with `no LaTeX face for 'Liberation Sans' (one face per template: newtx, tgschola, ebgaramond, gelasio)`
   (tools/fb/src/enginegen/gen.rs `latex_face`); nothing is generated, so neither latex nor the docx spec exists and
   XENG cannot run. Needs a `latex_face` entry for Liberation Sans/Arial with Arial's advances (helvet's uhvr carries
   Helvetica's, which match Arial's) and its ellipsis advance, the face's `latex_bias`, and `list_width`
   (lib/docx/xdoc.lua, measured on Times widths today) for that face. Folders: all eight above.
2. **Space that fills the page** (in "Not yet in the model"): the six brief and petition covers set `#v(1fr)` above
   and below the title block so the counsel block sits at the foot of the cover (e.g. `opening-brief/typst/
   fladistctapp-opening-brief.typ:206`, the same line in amicus-brief 208, answering-brief 216, and 206 in
   petition-for-discretionary-review, petition-for-review and reply-brief). The motion-brief and petition-for-writ
   have no cover and need only request 1; both number pages from 2 (`page_number.from: 2` in the model).
