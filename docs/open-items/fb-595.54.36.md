# fb-595.54.36: Supreme Court of Georgia folders on the shared document model

Bead fb-595.54.36 (the "Generated engines" checklist of docs/EVAL-LOOP.md, fb-595.54.12) for the nine folders under
`courts/eleventh-circuit/georgia/state/supreme-court`. Moved: `motion-brief` (typst on `lib/typst/xdoc.typ`, latex and
docx generated, `params.cross_engine: gate`, tier 1 0 failed and XENG-001..003 pass on every engine). Not moved: the
rest, for the reasons below; each keeps its template and engines as they were.

## Shared-model requests (for the serial lane fb-595.54.82)

| feature | folders | evidence |
|---|---|---|
| TeX Gyre Schola in LaTeX (`lib/latex/xeschola.lua` run by `lib/latex/xdoc.lua`; `fb engines gen` accepting the face) | `amicus-brief`, `answering-brief`, `brief-on-the-merits`, `opening-brief`, `petition-for-discretionary-review`, `reply-brief` | Each template sets `TeX Gyre Schola`, the vendored Century Schoolbook: SCt R 16(2) states its sizes in 13-point and 11-point Century Schoolbook and R 16(1) names the Century family (the court's rules.md, GA-SC-FONT-001, -002). `tools/fb/src/enginegen/gen.rs` `latex_face` refuses the face ("the shared document model does not set Schola in LaTeX yet"), so no latex engine can be generated. Changing these folders to Times New Roman is a face decision the bead does not make. |
| An item's number in `each` (e.g. `{#}`, from 1) | `petition-for-review` | SCt R 41(2): the questions presented under a heading at the very beginning; the template numbers them ("1.", a hanging indent of 36 pt) from the frontmatter list `questions_presented`. The model's `each` gives an item's fields and `{.}` only, so a petition with several questions would lose their numbers. |
| External links set as plain text (the link text kept, the target dropped) in typst, LaTeX and Word | `motion-brief` (moved; the sample has no link), every Georgia folder | SCt R 17(3) (GA-SC-ELEC-001): e-filed documents carry no hyperlinks to other documents or external sites. The old templates had `show link: it => if type(it.dest) == location { it } else { it.body }`; `lib/typst/xdoc.typ` and `lib/pandoc/xdoc.lua` keep a markdown link's target. `answering-brief`, `opening-brief` and `reply-brief` samples have 12, 20 and 14 markdown links. |
| The last body paragraph kept with the closing (already listed in docs/EVAL-LOOP.md, "Not yet in the model") | `motion-brief` (moved), `petition-for-review` | The old template set the last paragraph and the Rule 20(7) statement and signature block in one unbreakable block; on the model the closing stands alone on PDF page 8 of `OUTPUT-motion-brief.*.pdf` (Gate 2, ACCEPTED in motion-brief/README.md). |
| Space between body paragraphs (a `gap` for the body, as `quote.gap`) | `motion-brief` (moved), `petition-for-review` | The old templates set 7.8 pt (0.6 x the type size) between body paragraphs; the model's body paragraphs touch at the body pitch. Not a rule; ACCEPTED in motion-brief/README.md. |
