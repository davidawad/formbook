### Shared-model requests, second lane (feature, folders, evidence)

- **B1. The section-sign box swallows a footnote (LaTeX).** lib/pandoc/xdoc.lua binds the token after "§" in an
  `\mbox`; when a note follows that token the note goes into the box, and LaTeX drops a `\footnote` set inside an
  `\mbox`. The generated tex: `§~\mbox{11\mbox{-}10A\mbox{-}19(e),\footnote{West Virginia Code ...}}`.
  petition-for-discretionary-review: note 2 ("§ 11-10A-19(e),[^2]") missing on p10, the latex render runs 13 pages to
  typst's 14, and H.D. 4305 (cited only in that note) has no page ("--"). petition-for-review: note 48 ("§
  16-13A-8.”[^48]") missing on p13, pages 14-16 end differently. Fix: end the box before a note (Word's no-break
  binding may need the same check).
- **B2. A keyed link that starts with "§" (LaTeX, Word).** The page mark goes after the link's first word, which is
  "§" itself, and a breakable space follows it: `§\xd@amark{33} 22\mbox{-}6\mbox{-}8(e)`. LaTeX and Word break between
  "§" and the number where typst keeps them together. petition-for-rehearing p9 line 16 ("wellhead.” [§
  22-6-8(e)](toa:..)"), p10 line 5 ("[§ 22-6-8(a)(1)](toa:..)"); 416/420 lines in both engines. Fix: treat "§ n" (and
  "§§ n") as the first word.
- **B3. typst's keyed sort key keeps punctuation.** lib/typst/xdoc.typ `sort-key` puts `.replace(regex("[^a-z0-9
  ]"), "")` on a continuation line; in markup mode the `#let` ends at the newline, so typst sorts by the raw lower-case
  text while lib/pandoc/xdoc.lua strips it. typst: `" w. va. code §§ 55-7b-1 et seq."` after `" w. va. code §
  55-7b-9(g)"`; LaTeX and Word list "§§ 55-7B-1" first. petition-for-writ p3 (6 lines). Any keyed table whose entries
  differ only after punctuation is affected. Fix: parenthesize the expression.
- **B4. Word's page lookup misses repeated short citations.** The table of authorities in Word lacks a page that
  typst and LaTeX list when the authority's marks repeat the same text: brief-on-the-merits p3, Thompson (typst 14,
  15, 16; Word 14, 16), Scott (13, 14, 15, 16; Word 13, 15, 16), Trivett (13, 14; Word 13), whose marks on body page
  14 are the short-form notes 77-79 ("*Scott*, 246 W. Va. 184, 866 S.E.2d 350.") repeating notes 69-70;
  petition-for-discretionary-review p3, Hudkins (8, 9; Word 9), two marks of identical text. Lines and page ends are
  otherwise equal (622/625, 295/296).
- **B5. typst sets a note on another page than its mark** (already open in fb-595.54.82, "not implemented": 7
  folders; two more here). amicus-brief: note 14 on p10 while "failed.14" stays on p9, LaTeX moves the line on (21 of
  30 page ends differ, 31 pages to 30). brief-on-the-merits: note 3 on p6 while the quotation's last line
  ("emotional injury.3") stays on p5 (18 of 24 page ends differ).
- **B6. LibreOffice keeps a note's anchor line and sets the note on the next page** (fb-595.54.13, "no docx setting
  changes it"; reported there). reply-brief p6 ("such, both matters ... civil case.3"), petition-for-writ p9
  ("emotional distress claims.5").
- **B7. Word's footnote area** (already open, 8 folders). amicus-brief p12 holds one body line more in Word;
  petition-for-review p12 holds note 46 and its anchor line, which typst moves to p13.
- **B8. A keyed group's italic name with a comma; an entry without a cite.** The model prints an `italic` group's row

### Shared-model requests (pass 1; 1 settled, 4 implemented by fb-595.54.82)

1. **A footnote split across pages (LaTeX).** typst splits a long footnote over two pages. LaTeX keeps it whole and
   moves the line holding its reference to the next page, so every later page end differs. Already listed as
   fb-595.54.51 request 3 (Mississippi), and these are two more folders that need it:
   - reply-brief: footnote 3, p6 (body p2). LaTeX p7 starts at "such," where typst starts at "Therefore,". After
     that, 21 of 27 page ends differ and LaTeX runs 28 pages to typst's 27.
   - amicus-brief: footnote 14, p9 (body p3). LaTeX moves notes 13-14 and their lines on, and 15 of 30 page ends
     differ.
2. **Widow control (docx).** reply-brief p9/p10: typst carries two lines ("under Rule 1(b), ... merits" / "this
   appeal.8") to p10 rather than leave one line alone at the top of p10. LibreOffice sets the first of them on p9 and
   leaves "this appeal.8" as a one-line widow on p10 (docx p10 starts at "this", typst at "under"). After that, 15 of
   27 page ends differ. The model should set one widow/orphan rule in all three engines (Word's `widowControl`,
   LaTeX `\widowpenalty`/`\clubpenalty`, typst's default 2-line costs).
3. **Where a footnote is split (docx).** amicus-brief p10 (body p4): typst moves footnote 19 whole to the next page
   with its reference line, while LibreOffice splits it over p10/p11 (docx p11 starts at "2", typst at
   "liability"). This is the same need as request 1: one split rule for all engines.
4. **The keyed table of authorities with `toa:` link marks.** This is fb-595.54.51 request 5 (Mississippi) and
   fb-595.54.65 (California), and the same schema appears here. Six West Virginia folders give
   `authorities: {<key>: {kind: case|statute|constitution|rule|other, name, cite, sort?}}` and mark each citation in
   the body with `[text](toa:<key>)`: answering-brief has 78 marks and 28 authorities, brief-on-the-merits 77/43,
   petition-for-discretionary-review 21/14, petition-for-rehearing 41/34, petition-for-review 72/40 and
   petition-for-writ 48/27. The template groups the entries by `kind` under CASES / STATUTES / CONSTITUTIONAL
   PROVISIONS / RULES / OTHER AUTHORITIES, sorts each group by `sort` or `name`, italicizes a case name before its
   cite, and prints "passim" for seven or more pages. xdoc's `authorities` reads only
   `[{heading, entries: [{cite, find}]}]` and would fail on the map. The INPUTs are transcriptions and are not
   rewritten here (no new fields). These folders need either the keyed schema in the model (link marks, kind groups,
   sorting, passim) or a decision by David to convert the samples to the shared schema. Apart from that, their
   layout fits the reply-brief layout (cover, contents, authorities numbered i, ii .., `front: lower-roman`, the
   signature and service page), so the port is mechanical once the authorities exist.
5. **A rule inside a column (LaTeX).** A `{rule}` that is the only block of a `columns` cell has no width in
   LaTeX: lib/latex/xdoc.lua sets the cell as a `\vtop` whose width comes from its content, so the running `\hrule`
   gets 0 bp and disappears. typst and Word draw it across the cell. This was found with the motion's old short
   rules (a 216 pt rule beside an empty column). The motion now follows its filed exemplar, which has no rules, so no
   folder depends on it. `vtop` should set `\hbox to \hsize{}` or `\hrule width\hsize`.
6. **`valign: center` in docx.** The motion's lower-court column, centered beside a caption whose height differs,
   landed one line lower in LibreOffice than in typst (p1 line 7; baseline 13.8 pt off). The motion now aligns that
   column to the top.
