## Shared-model requests (for fb-595.54.82)

1. **The faces of Rule 9.045(b) in LaTeX and docx: TeX Gyre Bonum (Bookman Old Style) and Liberation Sans (Arial).**
   - Folders: TeX Gyre Bonum: `amicus-brief`, `answering-brief`, `motion-brief`, `opening-brief`, `reply-brief`.
     Liberation Sans: `petition-for-discretionary-review`, `petition-for-review`, `petition-for-writ`.
   - Evidence: FLADISTCTAPP4-FORM-005 (Rule 9.045(b) as amended by No. SC2025-1458, effective July 1, 2026) allows
     only Arial 14 or Bookman Old Style 14. `fb engines gen .../motion-brief` fails with "no LaTeX face for `TeX Gyre
     Bonum`", and `.../petition-for-review` with "no LaTeX face for `Liberation Sans`" (tools/fb/src/enginegen/gen.rs
     `latex_face`). Needed per face: a pdflatex package whose advances match the vendored font (`tgbonum` for Bonum;
     for Arial, `tgheros`/`helvet` must be measured against Liberation Sans first), the ellipsis advance, the
     `latex_bias`, Liberation Sans / Bonum advances in `list_width` (lib/docx/xdoc.lua), and `LEADER-MIN`
     (lib/typst/xdoc.typ) re-measured at 14 pt in LibreOffice. The same request is open for the Second and Third
     DCAs (fb-595.54.38, fb-595.54.37).
   - The pitches the two layouts use: Bookman Old Style 14 pt, 32.9 / 16.45 pt (measured on the filed motion,
     Word: 32.88 pt between double-spaced baselines); Arial 14 pt, 32.2 / 16.1 pt (the filed petition for writ:
     32.16 pt). TeX Gyre Bonum's own win line (1.337 em) is taller than Bookman's (about 1.174 em): the docx
     recipe must set the line exactly, not from the font.
2. **Headings numbered by the template.**
   - Folders: `petition-for-discretionary-review`, `petition-for-writ`.
   - Evidence: both templates number level-2 headings "I." and level-3 "A." (`heading-number`) with a 0.5 in hang;
     the INPUTs carry the heading text without the numbers (petition-for-writ's transcription note: "The template
     generates the Roman numerals of the argument points"). docs/EVAL-LOOP.md lists this as not in the model.
3. **Space that fills the cover page (typst `v(1fr)`).**
   - Folders: `amicus-brief`, `answering-brief`, `opening-brief`, `reply-brief`.
   - Evidence: each cover centers the title between the caption and counsel with `v(1fr)` above and below and puts
     counsel at the foot of the page. Fixed gaps would put counsel at another height
     for every caption and could push it past the page (DEF-COVER-001). Listed in docs/EVAL-LOOP.md as not in the
     model.
4. **A list item by index (`{signature.signer.0}`).**
   - Folders: `motion-brief` (and the briefs once moved).
   - Evidence: the old certificate of service was signed "/s/", the name and the bar number (the first `signer`
     line). `lookup` reads no array index, so on the model it is signed with the `/s/` line and the name only. That
     is still a signature; tier 2.
5. **An empty value kept as an empty line.**
   - Folders: `motion-brief`, `petition-for-review` (`parties[].role: ""` for the "v." line).
   - Evidence: the text block `{role}` gives an empty paragraph, which typst sets with no height; LaTeX and Word set
     a line. No visible difference in typst today, but the generated engines must agree with it (the same as
     fb-595.54.37 request 4).
