# fb-595.54.27: open items (Supreme Court of Florida)

Folders: `courts/eleventh-circuit/florida/state/supreme-court` and its nine doc types (amicus-brief, answering-brief,
brief-on-the-merits, motion-brief, petition-for-discretionary-review, petition-for-rehearing, petition-for-review,
petition-for-writ, reply-brief). Checked 2026-10-22 on master ce5f15268.

No folder could be gated (`params.cross_engine: gate`), and none was moved onto the shared model: all nine doc types
share one template (`typst/fla-<doctype>.typ`, the same code but for the counsel indent, the authorities page column
and a list-valued `proceeding`), and every one needs requests 1 and 2 below. The existing typst renders pass tier 1
(`check.sh --engine typst`: 8 passed, 0 failed, DEF-COVER-001, DEF-TOC-001 and DEF-FONT-002 PASS, on all nine).

## Shared-model requests (for fb-595.54.82)

1. **A sans-serif face: Arial / Liberation Sans in LaTeX (and Word's page-list width).**
   - Folders: all nine doc types.
   - Evidence: Fla. R. App. P. 9.045(b) (October 1, 2026 edition) allows only Arial 14 or Bookman Old Style 14 for
     computer-generated documents (rules.md FLA-FORM-004); the template sets Liberation Sans, Arial's metric twin.
     `latex_face` (tools/fb/src/enginegen/gen.rs) has no line for it ("no LaTeX face for `Liberation Sans`"), so
     `fb engines gen` cannot write latex/ or docx/. Needed as in fb-595.54.37 request 1 (Florida Third DCA): a face
     line (TeX Gyre Heros or helvet carry Arial's advances; measure the bias and the ellipsis advance as for newtx)
     and Liberation Sans in `list_width` (lib/docx/xdoc.lua), since every folder has a table of citations.
2. **Space that fills the page (typst `v(1fr)`) on a cover.**
   - Folders: all nine doc types.
   - Evidence: the cover (RAP 9.210(a)(1), FLA-COV-001) sets the court, case number, caption and proceeding at the
     top, then `v(1fr)`, the brief title, `v(1fr)`, and the counsel block at the foot of the page. With fixed `above`
     values the title and counsel move with every caption and proceeding length (the brief-on-the-merits proceeding
     has three lines, the answering brief one long line), and a long counsel list (amicus-brief: four names, eight
     lines) could push the cover past one page (DEF-COVER-001). Same request as fb-595.54.37 request 3.
3. **Justified body text** (tier 2, not mandated).
   - Folders: all nine.
   - Evidence: the template justifies body paragraphs, quotations and notes (`par(justify: true)`); the model sets
     every paragraph flush left (lib/typst/xdoc.typ has no `justify`). Rule 9.045(b) does not require either, so a
     move without it is acceptable, but the renders would change on every page; a layout key (`justify: true`)
     carried to `\xd@` paragraphs and Word's `w:jc="both"` would keep them.
