## Shared-model requests

1. **"Page X of XX" page numbers.** The same request as fb-595.54.56 (Connecticut Appellate Court). Practice Book
   § 67-2A(c) (CONN-FORM-007, mandatory): every page from the cover on is numbered at the bottom center "Page X of
   XX"; § 66-2 for motions (CONN-MOT-003) and § 84-5(a) for petitions (CONN-PET-002) the same. The templates set
   `Page #counter(page).display() of #counter(page).final().first()`; the model's `page_number` prints the number
   only, so a port would fail a tier-1 rule. Needed: a `page_number` format with the total (typst
   `counter(page).final()`, LaTeX the last page from the `.aux`, Word `PAGE` and `NUMPAGES`). Folders: all seven
   Connecticut Supreme Court doc folders.
2. **A table of authorities by key and category.** The Connecticut briefs mark each citation in the body as a
   markdown link `[cite](toa:<key>)` and list `authorities: [{key, category, text}]` (categories cases,
   constitutional, statutes, rules, other, printed under fixed group titles; "passim" over five pages). The model
   reads `authorities: [{heading, entries: [{cite, find}]}]` and finds the text. Porting means rewriting the
   INPUTs' frontmatter (new fields) and dropping 17 to 47 `toa:` links per INPUT; either the model reads the
   `toa:` form, or David decides the INPUTs move to `find`. Folders: Connecticut `amicus-brief`, `answering-brief`,
   `brief-on-the-merits`, `reply-brief`.
3. **A cover page fill.** Wis. Stat. 809.19(9) (WISCTAPP-COVER-002, mandatory): the appellant's brief cover is
   blue, the respondent's red, the reply brief gray, a nonparty brief green. The templates set
   `page(fill: cover-fill)` on the cover (opening `#bcd7f0`, reply `#d9d9d9`, amicus `#c6e7c1`); the model has no
   page fill, so a port would drop a tier-1 requirement. Needed: e.g. `cover_fill: "#bcd7f0"` (typst: the cover
   page's `fill`; LaTeX: `\pagecolor` for the cover page; Word: a cover section with a full-page shape, as Word's
   page background applies to the whole document). Folders: wisctapp `opening-brief`, `reply-brief`,
   `amicus-brief`, and `answering-brief`, whose current template sets a white cover where the rule asks for red
   (a tier-1 defect of that folder today, to fix with the feature).
4. **Words of named sections.** Wis. Stat. 809.19(8)(c)1 (WISCTAPP-LEN-001, -002): the length counts the statement
   of the case, the argument and the conclusion only, and the 809.19(8)(d) certification states that count. The
   templates count the level-1 sections so named (`counted-sections`); the model's `{body_words}` counts the whole
   body before the tail. Needed: e.g. `{body_words}` restricted by a layout list of level-1 headings. Folders:
   wisctapp `opening-brief`, `answering-brief` (neither INPUT carries a certified count).
5. **A section sign bound to its number only.** lib/typst/xengine.typ boxes `[§¶] \S+` (the whole word after the
   sign); lib/pandoc/xengine.lua `bind_signs` binds only the space after it. In "1915 Wis. Act 461, § 44m—1–2, 5–6,
   14" typst keeps "§ 44m—1–2," whole and moves it to the next line, LaTeX and LibreOffice break before the em
   dash. First differing line: wisctapp `motion-brief`, latex and docx, p6 line 11 (931/946 lines identical in
   latex; docx 926/946, page ends p7 to p9 move and settle by p10). The engines need one rule (box the whole word in
   LaTeX and Word, or the sign and the number up to the first dash in typst).
6. **Note marks read alike.** pdftotext reads some typst note marks in Liberation Serif as part of the word before
   them ("461;4", "304.6", "6.87).5", "judgment.”).4": the mark's box on the word's own line box), while it reads
   LaTeX's and Word's raised marks as words of their own ("461;" "4"); the marks look the same on the page. Other
   marks ("Sess.),3") are read apart in all three engines. XENG-003 counts each such line as differing. First
   differing lines: wisctapp `motion-brief` p6 line 4 (latex and docx), `petition-for-writ` p19 line 13 (latex
   and docx, the folder's only difference: 479/480 lines). Needed: typst's mark set as the other engines set it
   (xdoc.typ `super` with `typographic: false` is the likely cause, unverified), or the diff joining a raised mark
   to its word.
7. **A break after an opening bracket.** "plaintiff[ ] is a natural ..." (an alteration bracket): typst and
   LibreOffice do not break between "[" and "]" (Unicode LB14, OP SP* ×), pdfTeX breaks after "[". First differing
   line: wisctapp `petition-for-discretionary-review`, latex, p10 line 14 (366/373 lines identical; pages and page
   ends equal). docx passes. LaTeX needs the LB14 rule (no break after an opening bracket and its spaces).
8. **Implicit header references.** pandoc's markdown reader (implicit_header_references) reads a bracketed word that
   matches a heading ("[venue]" with a "### Venue" heading) as a link to it and drops the brackets; cmarker prints
   the brackets. wisctapp `petition-for-writ` p17 line 5: the INPUT now escapes the brackets (`\[venue\]`, the same
   text in every engine). The pandoc engines should read markdown without `implicit_header_references`.
9. **Quotation size.** Wis. Stat. 809.19(8)(b)3.c lets quotations be 11 point; the old templates set them at 11. The
   model's `quote` has no `size`, so the ported folders set quotations at the body's 13 point, single spaced (within
   the rule; tier 2). Footnotes keep 11 point (`footnote.size`).

## Tier 2, open (ported folders)

- wisctapp `motion-brief`, `petition-for-discretionary-review`, `petition-for-writ` (all engines): the date stands
  beside the signature block (left column), not above it as in the old templates: an empty first column of a
  `columns` block loses its width in LaTeX (lib/latex/xdoc.lua `columns` unboxes an empty `\vtop`), so the signature
  ran to the left margin there. The date fills the column instead. A shared-model fix (keep an empty column's
  width) would let the date go back above the signature.
- The covers set fixed space where the old templates set `v(1fr)` (the motion's old cover overlapped its title and
  counsel); the motion and petition covers fit on page 1 in every engine.
- `petition-for-discretionary-review` p6: the first argument heading moves to p7 with its paragraph (kept with what
  follows), leaving p6 half empty, as typst did before the port.
