## INPUT edits made for the pandoc engines (no change in the typst render)

- Paragraphs that open with "I.", "II.", "A.", "b." are escaped (`I\.`): pandoc reads them as ordered lists, cmarker
  (CommonMark) as paragraphs.
- Straight double quotes in the bodies are written as the curly quotes typst set (“ ”): pandoc's smart quotes pair an
  unbalanced or bracketed quote differently from cmarker ("Claimant) ..., "[s]hould, ("It). The typst text of every
  Iowa render is identical before and after; Wyoming's amicus changed only where typst had set an opening quote at the
  end of a quotation (now ”).
