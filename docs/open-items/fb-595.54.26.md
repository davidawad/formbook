## Shared-model requests (for fb-595.54.82)

1. **Paper size.** Feature: a `paper` (or `page: {width, height}`) key in layout.yaml. The model sets US Letter in
   every engine: `lib/typst/xdoc.typ:345` (`paper: "us-letter"`), `tools/fb/src/enginegen/tex.rs:97`
   (`letterpaper`), `tools/fb/src/enginegen/word.rs:177` and `lib/docx/xdoc.lua:326` (`<w:pgSz w:w="12240"
   w:h="15840"/>`). Louisiana's templates set legal paper, 8 1/2 x 14 in (612 x 1008 pt): Rule X 2(b) requires it for
   writ applications "to the extent practicable" (LA-FORM-002), Rule VII 2 allows letter or legal for briefs and the
   template chose legal for every doc type (LA-FORM-001, rules.md); the court's `eval.yaml` checks 612 x 1008
   (DEF-FORM-001, tier 1). Folders: all nine doc folders. A port onto the model today would fail DEF-FORM-001 on
   every page.
2. **Authorities keyed by kind, marked by link.** Feature: a table of authorities from a frontmatter map
   `authorities: {<key>: {kind, name, cite[, sort]}}`, grouped by `kind` under fixed court headings (Cases,
   Constitutional Provisions / Constitutions, Statutes, Rules, Other Authorities), alphabetical by `sort` or name, a
   case name in italics, "passim" from seven pages; the pages come from body links `[text](toa:<key>)` (footnotes
   included), not from a `find` string. This is request 1 of docs/open-items/fb-595.54.34.md (New York), with the
   link marks in addition. The model reads only `authorities: [{heading, entries: [{cite, find}]}]` and iterates the
   field whenever present, so these samples fail the typst render even without a layout `authorities` key. Folders
   (entries / toa links): amicus-brief 47/56, answering-brief 155/290, brief-on-the-merits 116/186,
   petition-for-discretionary-review 56/111, petition-for-rehearing 31/66, petition-for-review 54/139,
   petition-for-writ 32/58, reply-brief 14/25. Rewriting the INPUTs into the model's shape would change the court's
   markdown contract (a decision, not a port).
3. **Certificates and pages set from frontmatter markdown.** Feature: a page of its own after the closing with a
   level-1 style title, a frontmatter markdown text of one or more paragraphs at the body pitch, recipient address
   blocks two to a row, and a signature block. The model's `tail` sets only body text, and a `{text: "{field}"}`
   block of more than one paragraph reads as plain words in the pandoc engines (`lib/pandoc/xdoc.lua` `M.inlines`:
   "the plain words when it does not read as one paragraph") while typst renders paragraphs: the engines would
   differ. Folders: all nine (`certificate`; petition-for-discretionary-review's text has 2 paragraphs),
   amicus-brief (`compliance`, 4 paragraphs), motion-brief (`order`, 3 paragraphs).
4. **Consolidated captions.** amicus-brief's cover repeats the caption for each `consolidated` case under a "c/w"
   marker; expressible with `each` and `columns` once requests 1 to 3 exist (noted, not a model gap).
5. **An unnumbered page after the numbered body.** Feature: motion-brief's proposed order is its own page after the
   certificate, under the caption again (court, docket, parties, origin; no title, no counsel) and with no page
   number. The model numbers every page from `page_number.from` to the end. Folder: motion-brief.
