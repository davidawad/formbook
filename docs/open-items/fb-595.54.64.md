## Shared-model requests (for the serial lane fb-595.54.82)

1. **Headings numbered by the template** (already listed in docs/EVAL-LOOP.md "Not yet in the model").
   Folders: all five Hawaii ICA doc folders. Evidence: `hawapp-*.typ` `heading-label`: levels 2..5 print
   "I.", "A.", "1.", "a." in a 0.5 in box with the text hanging after it (`set heading(numbering: "1")`), and the
   table of contents repeats the label at the heading's indent (HRAP 28(b) sections; the INPUT headings carry no
   number, e.g. `## STATEMENT OF THE CASE` renders "I. STATEMENT OF THE CASE").
2. **Authorities from links, grouped by kind, with *passim*.** Folders: the five Hawaii ICA doc folders. Evidence:
   the INPUTs mark citations as `[text](toa:key)` and give `authorities:` as a map `key: {kind, name, cite}`; the
   table groups by kind (Cases, Constitutional Provisions, Statutes, Regulations, Rules, Other Authorities, in that
   order), sorts each group, sets a case as the italic name on one line and the cite hanging below, lists an entry
   on 7 or more pages as *passim*, and heads the first group with an underlined "Page(s)" (the contents with
   "Page"). The model reads only `authorities: [{heading, entries: [{cite, find}]}]` and text matches; converting
   the INPUTs would add fields and lose the link targets (a cite such as "§ 91-14(g)(1)" marks HRS § 91-14).
3. **A cover without tables.** Folder: nevada court-of-appeals motion-brief. Evidence: with `cover` and
   `page_number.front` but no `contents`/`authorities`, lib/latex/xdoc.lua never switches to arabic (body pages
   print "i", "ii", ..; `fb diff --engines` 231/242 lines) and lib/docx/xdoc.lua drops the cover entirely (its
   cover and sections are written only when `paged`; every page one early). The motion is ported with the caption
   page in `front`, a `{break: true}` and `page_number.from: 2`: the body prints 2, 3, .. (the cover counted;
   DEF-COVER-001 passes), where the filed exemplar and the old template print 1, 2, .. after an unnumbered caption.
   Tier 2, ACCEPTED until the model sets a cover apart without tables.
4. **A body part numbered with the tables** (`arabic_from_heading`). Folders: nevada court-of-appeals
   opening-brief, answering-brief. Evidence: `split-body` in `nevapp-*-brief.typ`: the body before the heading
   named by `arabic_from_heading` (NRAP 26.1 disclosure, jurisdictional and routing statements, issues) continues
   the tables' lower-roman numbers; the arabic count starts at 1 on that heading (the exemplars do the same).
5. **A front page numbered with the tables.** Folders: nevada court-of-appeals reply-brief, petition-for-writ.
   Evidence: the `disclosure` frontmatter (heading, paragraphs, date, signature) is set on its own page after the
   cover and before the contents, numbered "i" with the tables continuing ii, iii (the old templates note that an
   unnumbered disclosure read as a second cover and failed DEF-COVER-001).
6. **Space that fills a page** (already listed: `v(1fr)` on a cover). Folders: nevada court-of-appeals opening,
   answering, reply, petition-for-writ (the brief title and counsel spread down the cover). Fixed space would
   serve once 4 and 5 exist; recorded so the port need not lose the look.
7. **A caption cell ruled on its right side.** Folder: nevada court-of-appeals motion-brief. Evidence: the old
   template boxed the case title with a right and bottom stroke; the model has only full-width rules, so the port
   keeps the bottom rule. Tier 2, ACCEPTED.
8. **The last paragraph kept with the closing** (already listed). Folders: the five Hawaii ICA doc folders (the old
   template keeps the brief's last paragraph with the DATED/signature grid).
