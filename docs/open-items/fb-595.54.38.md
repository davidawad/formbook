## Shared-model requests

1. **An Arial face (Liberation Sans) in the generated LaTeX and docx engines.**
   - Folders: all eight doc folders.
   - Evidence: Fla. R. App. P. 9.045(b), as amended by No. SC2025-1458 (effective July 1, 2026; rules.md FLADISTCTAPP2-FORM-003), allows only Arial 14-point or Bookman Old Style 14-point. Bookman is not vendored, so every template sets `#let font-family = "Liberation Sans"` (the vendored metric twin of Arial). `tools/fb/src/enginegen/gen.rs` `latex_face` (line 146) knows only Times New Roman / Liberation Serif / TeX Gyre Termes, EB Garamond and Gelasio, and rejects any other face, so `fb engines gen` writes neither engine for these folders.
   - Needed with the face: a pdflatex package whose advances match Liberation Sans, so XENG-003 can pass (Helvetica clones such as `helvet`/`uhvr` are not Arial's metrics everywhere, so they must be measured first); the face's ellipsis advance (`latex_face`'s second value); its `latex_bias`; `lib/docx/xdoc.lua` `list_width` (line 256), which uses Times New Roman's digit, comma and hyphen advances; and a re-check of `LEADER-MIN` in `lib/typst/xdoc.typ` (measured on Times New Roman at 12 and 14 pt) at Arial 14 pt in LibreOffice.

2. **A word count that the template computes from the body.**
   - Folders: `amicus-brief`, `answering-brief`, `opening-brief`, `petition-for-discretionary-review`, `petition-for-review`, `petition-for-writ`, `reply-brief`. `motion-brief` does not need it (Rule 9.300 sets no limit; FLADISTCTAPP2-MOT-002).
   - Evidence: FLADISTCTAPP2-CERT-001 and CERT-003 (Rule 9.045(e)) are tier 1. They require a certificate of compliance that states the word count, which excludes the cover, tables, certificates and signature block. Each template counts the markdown body (`body-words`) and asserts the limit (LEN-001, LEN-003, AMIC-002). The INPUTs carry no count in their frontmatter, and the checklist allows no new fields. docs/EVAL-LOOP.md lists "word counts the template computes" as not yet in the model.

3. **Space that fills the cover page (`v(1fr)`), or a decision to use fixed gaps.**
   - Folders: all eight. Each cover places the title and the counsel block with `v(1fr)`.
   - Evidence: listed in docs/EVAL-LOOP.md as not in the model. This one is a folder-level change if fixed gaps are accepted, as the Georgia briefs did with fixed 1 in gaps. It is recorded here because the move is blocked by items 1 and 2 anyway.
