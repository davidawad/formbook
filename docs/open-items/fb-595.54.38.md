## Blocked: shared model and host toolchain

No doc folder was moved to the shared model, no LaTeX or DOCX engine was generated, and no folder can
be gated with `params.cross_engine: gate` in this checkout.

1. **The generated LaTeX engine does not support Liberation Sans.** All eight current typst templates
   declare `Liberation Sans` as the metric-compatible Arial face required by Rule 9.045(b). Calling
   `tools/fb/target/release/fb engines gen .../petition-for-review` reports that
   `typst/layout.yaml` is missing and the folder is not on the shared model. The shared-model checklist
   in `docs/EVAL-LOOP.md` also records that the generator has no LaTeX face for Liberation Sans. The
   shared model needs a stock-pdflatex face/package with matching advances, measured ellipsis advance
   and LaTeX width bias, plus DOCX page-list width and 14 pt leader checks for this face. The court rule
   allows Arial or Bookman Old Style; substituting Times or another face would violate tier 1.
2. **All eight covers use remaining-page fill.** Each current cover has `v(1fr)` above and below its
   title/counsel content. The shared model checklist lists this block as unsupported. Fixed gaps would
   change the placement as case captions and counsel lists vary, so the model needs an equivalent
   fill-space block in typst, LaTeX and DOCX before these templates can be moved faithfully.

The court root itself has no template and no `usage/INPUT-*.md`; it has only filed examples and is
not a generated-engine target.
