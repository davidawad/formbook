## Shared-model requests (for fb-595.54.82)

1. **An Arial face (Liberation Sans) in the generated LaTeX and docx engines.**
   - Folders: all eight doc folders.
   - Evidence: Fla. R. App. P. 9.045(b) requires Arial 14-point or Bookman Old Style 14-point (court-root `eval.yaml`;
     rules.md FLADISTCTAPP1-FORM rows). Bookman is not vendored, so the template sets
     `#let font-family = "Liberation Sans"` (the vendored metric twin of Arial). `tools/fb/src/enginegen/gen.rs`
     `latex_face` (line 146) knows only Times New Roman / Liberation Serif / TeX Gyre Termes, EB Garamond and Gelasio
     and refuses every other face, on this tree and on origin/master at afbb201d3.
   - Needed with the face, as fb-595.54.38 lists: a pdflatex package with Arial's advances (measured), its ellipsis
     advance, its `latex_bias`, `list_width` in `lib/docx/xdoc.lua` for this face, and a re-check of `LEADER-MIN` in
     `lib/typst/xdoc.typ` at Arial 14 pt in LibreOffice.

2. **A text block with an alternative when a field is missing (an `else` for `when`, or `unless`).**
   - Folders: the six whose INPUT has no `word_count`: `amicus-brief`, `motion-brief`, `opening-brief`,
     `petition-for-discretionary-review`, `petition-for-writ`, `reply-brief`. (`answering-brief` and
     `petition-for-review` give `word_count`.)
   - Evidence: FLADISTCTAPP1-CERT-001 and -CERT-003 (Rule 9.045(e)) are tier 1. They require a certificate of
     compliance, signed by counsel, right after the certificate of service. The template prints the count from
     `word_count`, or a blank line for counsel to fill in when it is not given. The model's `optional` drops the
     whole paragraph when the field is missing, and `when` has no else. A port would therefore drop the certificate
     from those six documents. A template-computed word count (listed as missing in docs/EVAL-LOOP.md) would also
     cover this.

3. **Headings the template writes, listed in the table of contents.**
   - Folders: all eight.
   - Evidence: the template sets "Certificate of Service" and "Certificate of Compliance" as level-1 headings after
     the signature block, and the table of contents lists both (`answering-brief/usage/OUTPUT-answering-brief.typst.pdf`
     page 2, last two rows). In the model, `closing` blocks are plain text and do not appear in `contents`. `tail`
     sets only certificates that the markdown body writes, and these INPUTs leave the certificates to the template.

4. **The first signer of a list (`first_signer_only`).**
   - Folders: all eight (the certificates' signature, `service.first_signer_only`, default true).
   - Evidence: the certificate signatures use only `signature.signers[0]`. In `lib/typst/xdoc.typ`, `lookup`
     (line 35) walks dictionaries only, so `{signature.signers.0.name}` is not a path. `each: signature.signers` signs
     with every signer. That matches the current INPUTs, which have one signer each, but it is not the template's rule.

5. **Space that fills the cover page (`v(1fr)`), or a decision to use fixed gaps.**
   - Folders: all eight. The cover sets the title and the counsel block with `v(1fr)` above and below the title.
   - Evidence: docs/EVAL-LOOP.md lists this as not yet in the model. If fixed gaps are accepted (as the Georgia briefs
     did), it becomes a folder-level change. That is a decision for David.

The template also prints "passim" for an authority found on more than six pages. The model lists every page. None of
the current INPUTs reaches seven pages for one authority, so this is tier 2 and is noted only.
