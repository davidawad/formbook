# fb-595.54.74: open items

Generated engines fan-out (docs/EVAL-LOOP.md, "Generated engines") for the Nebraska Court of Appeals, the Supreme Court
of South Dakota and the Texas Judicial Panel on Multidistrict Litigation. The three court roots hold no template (only
`court.json`, `rules.md`, `eval.yaml` and filed examples), so there is nothing to port in them.

## Decisions taken (not shared-model requests)

- **Nebraska Court of Appeals, all four briefs: Times New Roman instead of TeX Gyre Schola.** NEBCTAPP-FORM-006
  (§ 2-103(A)(4)) prefers Century or Century Schoolbook and allows Times New Roman; docs/FONTS.md rule 6 (David,
  2026-10-17) makes Times New Roman the template face wherever the rule allows it. The shared model has no Schola in
  LaTeX either (docs/EVAL-LOOP.md, "Not yet in the model"). None of the four exemplars has an entry in
  `data/exemplar-fonts.json`, so no `template_face` is needed there (`fb lint fonts` passes).
- **Nebraska INPUTs:** an empty string in a frontmatter line list (`""`, a blank line in a counsel or signature block,
  an empty signature label) is now a no-break space. The model sets `""` differently per engine: typst drops the
  empty paragraph, Word keeps a blank line, and LaTeX collapses a column whose only paragraph is empty to zero width.
  The opening brief's `[COUNSEL FOR BIG IRON]:` quotation lines are escaped (`\[`): CommonMark (pandoc) reads them as
  link reference definitions and drops them, cmarker printed them.
