# fb-595.54.81: open items

Bead fb-595.54.81 moves thirteen folders onto the shared document model (docs/EVAL-LOOP.md, "Generated engines",
fb-595.54.12). All thirteen are court roots (the folder with `court.json`). None has a doc-type folder, a typst
template or an INPUT. `typst/` and `latex/` hold only `.gitkeep`, and there is no `docx/` folder. The checklist starts
from "the folder's typst template" (step 1) and writes `layout.yaml` from "every number of the old template" (step 2).
With no template there is nothing to move and nothing for `fb engines gen` to generate. `fb engines gen` on one of them
says: `typst/layout.yaml: No such file or directory (not on the shared document model)`.

Result: **no folder ported, none gated**. Nothing in these folders was changed, and `params.cross_engine` was not set.
With no engine output, XENG-001..003 have nothing to compare. A `gate` would gate nothing.
