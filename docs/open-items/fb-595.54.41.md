## Shared-model requests (for fb-595.54.82)

1. **The two faces Rule 9.045(b) allows: Arial (Liberation Sans) and Bookman Old Style (TeX Gyre Bonum).**
   - Folders: all eight doc folders. Liberation Sans: `petition-for-discretionary-review`, `petition-for-review`,
     `petition-for-writ`. TeX Gyre Bonum: `amicus-brief`, `answering-brief`, `motion-brief`, `opening-brief`,
     `reply-brief`.
   - Evidence: Fla. R. App. P. 9.045(b) (rules.md FLADISTCTAPP5-FORM-005) allows only Arial 14 or Bookman Old Style
     14. `fb engines gen .../petition-for-review` fails with "no LaTeX face for `Liberation Sans` (one face per
     template: newtx, tgschola, ebgaramond, gelasio)" (tools/fb/src/enginegen/gen.rs `latex_face`). TeX Gyre Bonum
     is not in that list either. The same request is open for the Second and Third DCAs (fb-595.54.38 request 1,
     fb-595.54.37 request 1). For each face the model needs a pdflatex package with matching advances (`tgbonum` for
     Bonum; `tgheros` or `helvet` for Arial, measured first), the ellipsis advance, `latex_bias`, `list_width` in
     lib/docx/xdoc.lua (tables of authorities), and a re-check of `LEADER-MIN` at 14 pt in each face.
2. **Space that fills the cover page (typst `v(1fr)`).**
   - Folders: `amicus-brief`, `answering-brief`, `opening-brief`, `reply-brief`, and `motion-brief` when its
     frontmatter sets `cover_page: true` (its INPUT sets `false`).
   - Evidence: each cover places the title and the counsel block with `v(1fr)` above and below. This is listed in
     docs/EVAL-LOOP.md as not in the model. Fixed gaps would put counsel at a different height for every caption
     length.
3. **Headings numbered by the template.**
   - Folders: `petition-for-discretionary-review`, `petition-for-writ`.
   - Evidence: the templates number level-2 headings "I." and level-3 headings "A." (`heading-number`). The INPUT
     headings carry no numbers (for example, petition-for-discretionary-review INPUT line 104 is `## The Trial
     Court's Order Departed ...`). Listed in docs/EVAL-LOOP.md as not in the model.
4. **An empty line between items of a list field, and a list item by index.** (Tier 2.)
   - Folders: `petition-for-writ` (signature `preface` group, then a blank line, then the signer).
   - Evidence: the same as fb-595.54.37 requests 4 and 5. The model sets an empty paragraph with no height in typst,
     so the group gap has to be a block's `above`, which works only when the groups are separate fields.
