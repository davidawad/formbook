# District Courts of Travis County, Texas (txdistrict-travis)

Doc types: `original-answer`, `motion-brief` (also renders a proposed order). Rules, sources and date read: `rules.md`. Shared template code: `typst/travis-common.typ`. Alias choice: the Texas district courts have no CourtListener id; the alias follows the `calsuperct-sandiego` pattern (`tx` + `district` + county). Status is `todo` (never set `done`; the owner does).
