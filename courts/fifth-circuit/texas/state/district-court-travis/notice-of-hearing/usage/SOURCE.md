# Exemplars: notice-of-hearing (txdistrict-travis)

Notices of hearing (TRCP 21(b)) filed in Travis County district courts: 1 and 2 after Travis Local Rules took effect (2024-11-15), 3 before. Each is a state-court filing (Travis County District Clerk e-filing stamp) attached to a removal file in the W.D. Tex. (Austin) and published in the CourtListener RECAP archive. Only the notice pages are stored (`qpdf --pages`). Retrieved 2026-10-25; each URL returned HTTP 200 the same day. The CourtListener docket pages return 403 to non-browser clients, so they are context only. None of the three is on a Rule 91a or other dispositive motion; none was found.
