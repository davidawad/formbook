# Exemplars: notice-of-appearance (txdistrict-travis)

Notices of appearance / designation of attorney in charge (TRCP 8) filed by defendants' counsel in Travis County district courts. Each is a state-court filing (Travis County District Clerk e-filing stamp) attached to a removal file in the W.D. Tex. (Austin) and published in the CourtListener RECAP archive. Only the notice pages are stored (`qpdf --pages`). Retrieved 2026-10-25; each URL returned HTTP 200 the same day. The CourtListener docket pages return 403 to non-browser clients, so they are context only.
