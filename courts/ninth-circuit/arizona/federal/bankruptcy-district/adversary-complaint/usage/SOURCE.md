The filed complaint's caption leaves its adversary-number field blank. The transcribed sample preserves that blank. The sample covers the complaint text and prayer; the filed certificate-of-service block is omitted because the current Typst template has no certificate-of-service input.

This is the first public filed exemplar found for this folder. It is one filer, so it is evidence for comparison but not enough to distinguish shared conventions from filer-specific style. A second exemplar from a different filer remains useful for a complete tier-2 convention review.
