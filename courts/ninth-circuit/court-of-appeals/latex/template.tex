% Cross-engine layout (docs/EVAL-LOOP.md, "Cross-engine gate"; fb-595.54). This template sets every line and page
% break where the typst template (the reference) and the Word template set them:
%   * the same glyph widths: newtx is Times metrics in TeX points, so sizes are given in bp (14 bp = typst's 14 pt);
%     no kerning and no ligatures (\pdfnoligatures turns both off in pdfTeX; typst and Word set neither);
%   * first-fit line breaking, as Word and typst break ragged text: a fil right skip makes every line equally good,
%     interword spaces neither stretch nor shrink, and every break costs nothing, so TeX's optimum is the
%     greedy one (of the breakings with the fewest lines it keeps the one whose lines come latest);
%   * fixed line boxes: every line is \pdfeachlineheight + \pdfeachlinedepth high, the baseline at 0.8 of its
%     pitch (Word's exact line spacing); boxes touch (\lineskip 0, \baselineskip 0); the first box of a page
%     starts at the top of the text block and the last must end inside it (\topskip 0, \maxdepth 0);
%   * spacing between blocks in bp, the larger of the space below one and above the next (\addvspace), dropped at
%     the top of a page; no widows or orphans.

% [space]: above / below each kind of heading. A heading never ends a page: \nobreak after it (the skip after a
% penalty is no place to break either; no \nobreak after the skip, or \addvspace above the next block would not see it
% and the two would add up), and the next paragraph has no orphan.
% ---- level 1: section headings, 16 bp bold capitals, centered (CA9-FORM-009) -----
\newcommand\ca@sechead[2]{% #1 title, #2 the contents entry (and bookmark)
  \par\addvspace{21bp}%
  \begingroup\centering\ca@headtype\bfseries\leavevmode#2\MakeUppercase{#1}\par\endgroup
  \nobreak\addvspace{15.4bp}}

% ---- level 2 in the Argument: centered point heading, bold (CA9-FORM-009). Not small capitals: Times New Roman

  \par\addvspace{16.8bp}%
  \begingroup\centering\ca@single\bfseries\leavevmode#3#1#2\par\endgroup % the label ends in its space
  \nobreak\addvspace{14bp}}

  \hskip#1\relax#5\makebox[#2][l]{#3}#4\par\endgroup
