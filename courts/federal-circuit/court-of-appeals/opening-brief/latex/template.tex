% U.S. Court of Appeals for the Federal Circuit: opening brief (principal brief of the appellant), LaTeX engine.
%
% Rule-driven and content-agnostic, the same layout as ../typst/cafc-opening-brief.typ (the reference for this
% court). No case-specific text, no coordinates measured off any filed brief, no forced line breaks. Built by
% tools/render.sh --engine latex: pandoc reads the markdown with cafc.lua (the same directory), this template is
% compiled with stock pdflatex, and the contents and authorities are written to the aux file and read back until it settles.
%
% Cross-engine layout (docs/EVAL-LOOP.md, "Cross-engine gate"): this template sets every line and page break where
% the typst template (the reference) sets them. The model itself (no kerning or ligatures, first-fit breaking, fixed
% line boxes, no widows, footnote marks, list labels, contents rows) is the shared package lib/latex/xengine.sty,
% which fb render inlines into the generated .tex in place of \usepackage{xengine}; the inline rules are
% lib/latex/xengine.lua, run by cafc.lua. Every size and space here is in bp (14 bp = typst's 14 pt), and blocks are
% spaced with \addvspace (the larger of the space below one and above the next). [name] refers to the typst template.
%
% Pandoc variables: the frontmatter fields, words_fmt, toa, addendum, interest_for (set by cafc.lua).

      }
      { }
  }
