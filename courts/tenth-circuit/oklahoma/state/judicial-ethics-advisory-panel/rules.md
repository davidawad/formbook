# Oklahoma Judicial Ethics Advisory Panel: filings

Alias `oklajeap`. Scope: the Judicial Ethics Advisory Panel is a non-adjudicative advisory body. It answers written requests from judges and judicial candidates about the Code of Judicial Conduct with advisory opinions. It has no parties, docket, briefs, motions, writs, review or amicus practice, so it receives no filed documents that this folder could template. The scope is taken from the Panel's own description in `usage/SOURCE.md` (every doc type there is BLOCKED for this reason). The Oklahoma Statutes Title 5 file checked for this court (https://www.oklegislature.gov/OK_Statutes/CompleteTitles/os5.rtf, HTTP 200, 2026-10-22) does not contain the Panel's rules or the Code of Judicial Conduct. Verified against Oklahoma Statutes Title 5 (Oklahoma Legislature, complete title) on 2026-10-22.
