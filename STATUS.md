## Typst per doc type: summary

One row per doc-type folder (`COURT/<doctype>/`), plus the court folder itself as "(court root)" when it has its own `typst/main.typ`. Complete = all four present, each keyed on committed text so a checkout without PDFs counts the same: Typst template (`typst/main.typ`), sample (`usage/INPUT-<doctype>[-<n>].md`), render (template and sample committed), exemplar (a `FILED-EXAMPLE-<doctype>[-<n>].pdf` named in `usage/SOURCE.md`). Overlays are generated on demand into `.overlay/` and are not counted. Status: **up for review** = `fb check` (court checks.yaml, else the default set in `data/checks-default.yaml`) left a valid typst stamp for the folder (`just eval` re-runs it); **in progress** = something is present; **todo** = nothing. A court is up for review when it has `rules.md` and every doc folder under it with an INPUT is up for review. `done` is set by hand in `court.json`.
